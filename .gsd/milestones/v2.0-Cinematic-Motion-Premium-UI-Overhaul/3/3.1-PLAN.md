# Plan 3.1: Dynamic Custom Cursor & Magnetic UI

## Objective
Implement a globally tracked, GSAP-driven custom cursor. Hide default browser cursors. Create a `MagneticHover` wrapper component that applies physics-based mouse-pull logic to interactive elements to elevate the premium feel.

## Context
- .gsd/SPEC.md
- src/components/CustomCursor.tsx (to create)
- src/components/MagneticHover.tsx (to create)
- src/app/layout.tsx (to integrate cursor)
