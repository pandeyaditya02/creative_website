## Lessons Learned
- When refactoring large UI components with complex scroll interactions, maintaining the macro-whitespace and brutalist typography contract is paramount. 
- GSAP `toggleActions` is a highly effective way to manage scroll state organically in React without tearing down and rebuilding listeners.
- Using Stitch MCP accelerates the creation of high-end, brutalist split layouts and ensures perfect structural markup.
- React Refs must be managed carefully when mixing Next.js Client Components and GSAP ScrollTriggers to prevent layout thrashing and DOM unmounting logic errors.
