## Data Flow

1. Initial layout renders globally applied styles, custom fonts, cursor, and navbar.
2. The user scrolls the page, triggering GSAP `ScrollTrigger` instances attached to `PinnedSection` wrappers.
3. Each section updates its visual state (scaling, translating, parallax) entirely locally within the client-side component logic, without needing external data fetching beyond static imports.
